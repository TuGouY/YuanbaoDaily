# YuanbaoDaily

> 让腾讯元宝的每日福利任务自动完成 —— 问元宝、写作、P 图、拍题、做同款，做完自动复核。

## 它解决什么问题

元宝「福利中心」每天有五项任务，每项要做 3 次才有积分：

| 任务 | 需要的操作 |
| --- | --- |
| 问元宝问题 | 提问 3 次 |
| 使用写作能力 | 生成 3 篇 |
| 使用 P 图能力 | 处理 3 张图 |
| 使用拍题能力 | 拍 3 道题 |
| 使用推荐模板做同款 | 用模板生成 3 次 |

手工点下来十几分钟。这个模块把整套流程自动化：**先读服务端进度 → 只补没做完的 → 做完回福利中心复核 → 没涨就再补**，全程不需要人盯着。

## 特性

- **两种版本**
  - `root`：LSPosed 模块，注入元宝进程，速度快、稳定性最好
  - `noroot`：独立无障碍 App，免 root，可与 root 版共存
- **进度以服务端为准**：直接调用页面自己的 `activity_center/get-current-tasks`，拿不到才退回界面文字
- **只补缺口**：已经 3/3 的任务不会重复刷
- **不打断你**：只有从模块里启动元宝才会自动执行；你自己点开元宝时，模块只读进度不动手
- **失败不瞎点**：定位不到安全落点就放弃并记录，不会乱点

## 安装

到 [Releases](../../releases) 下载对应版本：

**root 版（推荐）**
1. 手机已 root，装好 LSPosed（Zygisk 版）
2. 安装 APK，在 LSPosed 里启用模块，**作用域勾选「元宝」**
3. 重启手机

**免 root 版**
1. 安装 APK
2. 打开 App，按提示开启无障碍服务
3. 部分机型还需允许「自启动 / 后台运行」，否则息屏后被系统杀掉

首次使用建议在模块界面点一次「立即执行一次」，走一遍完整流程确认可用。

## 工作原理

```
┌──────────────┐   RUN 请求   ┌─────────────────┐
│  模块 UI     │ ───────────▶ │ 元宝进程（注入） │
│ (设置/进度)  │ ◀─────────── │  调度器 + 适配器 │
└──────────────┘  进度广播     └────────┬────────┘
                                        │ 无障碍操作
                                        ▼
                               ┌─────────────────┐
                               │ 元宝界面/福利中心│
                               └─────────────────┘
```

- **执行**：通过无障碍服务读界面、点按钮、写输入框，全部走系统 API，不 hook 业务逻辑
- **进度**：优先在福利中心页面里调用它自己的 JS Bridge 查任务列表；接口不通就用界面文字兜底
- **不做的事**：不修改元宝安装包、不伪造请求、不抓取账号凭证、不上传任何数据

## 从源码构建

需要 JDK 17+、Android SDK 34。

```bash
# root 版
./gradlew assembleXposedRelease
# 免 root 版
./gradlew assembleLiteRelease
# 单测
./gradlew testXposedDebugUnitTest testLiteDebugUnitTest
```

产物在 `app/build/outputs/apk/`。release 用 debug 签名，方便自己构建安装；要发布请自行配置签名。

## 兼容性

- Android 10 及以上（minSdk 24）
- 元宝 **2.93.0** 实测通过
- 元宝改版可能导致某项任务失效，通常表现为日志里 `fillText channel=none` 或找不到入口

## 常见问题

**Q：装完没反应？**
A：root 版检查 LSPosed 作用域是否勾了元宝、是否重启过；免 root 版检查无障碍服务是否还在运行。

**Q：某个任务一直不执行？**
A：多半是元宝改版了。开日志（`adb logcat -s YuanbaoDaily`）看卡在哪一步，欢迎提 issue 并附上日志。

**Q：会被封号吗？**
A：模块只做「模拟人手点击」，不伪造请求。但自动化操作本身可能违反元宝用户协议，风险自负，建议只在自己的账号上低频使用。
